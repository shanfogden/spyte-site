# Spyte Digital Media — offer landing page

Static one-page site for the Gapfinder-style AI Marketing Audit offer, rebranded to
Spyte Digital Media. Pure HTML/CSS, no build step, no dependencies beyond Google Fonts.

## Files
- `index.html` — the landing page. Swap `hello@yourdomain.com` for a real inbox or
  payment link before sending traffic to it.
- `assets/spyte-icon.svg` — icon-only mark (black badge, white bolt), self-contained,
  good for a favicon or social avatar.
- `assets/spyte-logo-black.svg` — full logo lockup for light backgrounds.
- `assets/spyte-logo-white.svg` — full logo lockup for dark backgrounds.

## Publish with GitHub Pages (free, no server needed)
1. Push this repo to GitHub (see the commands you were given alongside this file).
2. On GitHub: repo → **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch
   `main`, folder `/ (root)`. Save.
4. Your site goes live in 1–2 minutes at `https://<your-username>.github.io/<repo-name>/`.
